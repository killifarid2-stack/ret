# Deployment Handoff

## Commands
`npm install`
`npm run production:check`
`npm run mat:check`
`npm run release:verify`
`npm run production:final-check`

## Required real-world inputs
- Production URL
- Supabase Production URL/key values
- Vercel project/account access
- MAT device identities
- Operator accounts
- Backup destination

## Rule
Do not commit real credentials to this package.
