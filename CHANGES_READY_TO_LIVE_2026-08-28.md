# READY → LIVE — 2026-08-28

- In Par Équipe Team Call, pressing **READY** keeps the current call frame visible for exactly **3 seconds**.
- After the 3-second delay, the public display hands off to the **LIVE MATCH** screen automatically.
- The call screen is explicitly deactivated during the hand-off so the READY/call overlay cannot remain above the live scoreboard.
- Existing match, score, timer, Team Call and broadcast logic are preserved; this is only the READY → LIVE transition.
